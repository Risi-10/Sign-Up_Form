# Sign-Up Form

A sign-up page built as part of [The Odin Project](https://www.theodinproject.com/)'s Intermediate HTML and CSS course.

The project recreates a provided design, featuring a two-column layout with an image sidebar and a registration form.

## Built With

- HTML5
- CSS3 (Flexbox, positioning, custom fonts, and form styling)

## Features

- Image sidebar with Odin branding
- Registration form with six input fields
- Custom font using `@font-face`
- Input focus and validation styling
- Styled account creation button
